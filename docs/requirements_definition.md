# 移動距離計測アプリ（トラベルメーター） 要件定義書

## 1. アプリ概要

本アプリは、従来の「歩数計（ペドメーター）」のコンセプトをベースにしつつ、歩数ではなく**「移動距離（メートル / キロメートル）」**に特化して計測・可視化するAndroidアプリケーションです。
最大の特徴として、単なる総移動距離だけでなく、**「時間単位（毎時）」の移動距離**をタイムラインやグラフ形式で確認できる機能を備えています。

---

## 2. 目的・背景

- **歩数の不正確さの解消**: 歩数計は歩幅の設定や端末の持ち方（ポケット、バッグ、手持ち）によって誤差が生じやすい。GPS等の位置情報を用いて実際の移動距離を正確に把握したいというニーズに応える。
- **移動パターンの可視化**: 「何時頃にどれくらい移動したか（通勤時間帯、外出時など）」を時間単位で把握することで、日々の活動量や移動のタイムラインを直感的に振り返ることができるようにする。
- **健康管理・ライフログ**: ウォーキング、ランニング、毎日の通勤・通学、お出かけの記録として活用できるシンプルで使いやすいログアプリを提供する。

---

## 3. ターゲットユーザー

- 日々の散歩やウォーキング、ランニングの成果を「距離」ベースで記録・確認したい方
- 通勤や移動のスケジュール・活動量を時間単位で振り返りたい方
- シンプルでバッテリー負荷の少ない位置情報トラッカーを求めている方

---

## 4. 機能要件

### 4.1. コア機能（移動距離計測）
- **リアルタイム計測**: GPS（位置情報サービス）を利用して、バックグラウンド/フォアグラウンドで移動軌跡および移動距離を継続的に計測する。
- **移動判定**: ユーザーが静止している状態と移動している状態を自動判別し、GPSのノイズによる誤差を軽減する。
- **計測開始/停止**: ユーザー任意のタイミングで計測の開始・一時停止・終了を行える機能。

### 4.2. 時間単位の移動距離表示
- **時間別集計**: 1時間ごとの移動距離（例: 8:00〜9:00は1.2km、9:00〜10:00は0.5km）を集計して表示する。
- **グラフ/タイムライン表示**: 
  - 当日の24時間を時間軸（バーチャートやタイムラインリスト）で視覚化。
  - 最も移動が多かった時間帯のハイライト。

### 4.3. 履歴・ダッシュボード機能
- **日別・週別・月別サマリー**: 過去の移動距離の総計および時間別内訳をカレンダーやリスト形式で閲覧できる。
- **統計情報**: 平均移動距離、最長移動日、よく動く時間帯の傾向表示。

### 4.4. 設定・管理機能
- **目標設定**: 1日の目標移動距離（例: 5km）の設定と達成率の表示。
- **権限管理**: 位置情報権限（「常に許可」または「アプリの使用中のみ」）および通知権限の分かりやすいガイド。
- **バッテリー最適化設定**: 省電力モードや高精度モードの切り替えオプション。

---

## 5. 非機能要件

### 5.1. パフォーマンス・省電力
- **バッテリー消費の抑制**: 常時GPSを使用するため、Fused Location Provider APIを活用し、移動検知や適切なサンプリング間隔の調整によってバッテリー消費を最小限に抑える。
- **フォアグラウンドサービス**: バックグラウンドでの安定した計測のため、Androidのフォアグラウンドサービス（Foreground Service）と常時通知を実装する。

### 5.2. セキュリティ・プライバシー
- **位置情報の保護**: 取得した位置情報は端末内（Roomデータベースなど）に保存され、ユーザーの同意なく外部サーバーへ送信しない。
- **権限の適切な要求**: Androidの最新ガイドラインに準拠し、ランタイムパーミッションを適切にハンドリングする。

### 5.3. 動作環境
- **対応OS**: Android 8.0 (APIレベル 26) 以上
- **UIデザイン**: Material 3デザインシステムに準拠し、ダークモードに対応したモダンで直感的なインターフェース。

---

## 6. 画面設計イメージ

1. **ホーム画面（ダッシュボード）**
   - 今日の総移動距離（大きく表示）
   - 目標達成プログレスリング
   - **時間単位の移動距離グラフ**（直近の推移、または24時間バーチャート）
   - 計測の開始 / 停止ボタン

2. **履歴・詳細画面**
   - 日付選択カレンダー
   - 選択した日の時間別詳細リスト（0:00 〜 23:00の移動距離）

3. **設定画面**
   - 1日の目標距離設定
   - 通知設定
   - プライバシーポリシー・ヘルプ

---

## 7. データ構造案（ローカル DB: Room）

- **`LocationLogEntity` (位置情報ログ)**
  - `id`: Long (PK)
  - `timestamp`: Long (記録日時)
  - `latitude`: Double (緯度)
  - `longitude`: Double (經度)
  - `distance`: Float (前回点からの移動距離 meters)

- **`HourlySummaryEntity` (時間別集計)**
  - `id`: Long (PK)
  - `date`: String (YYYY-MM-DD)
  - `hour`: Int (0〜23)
  - `totalDistance`: Float (その時間の総移動距離 meters)
